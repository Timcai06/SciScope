## 一、这次证明的是什么

本次目标不是伪造离线 fixture，而是用**真实 FastAPI + 真实 HTTP + 真实 SSE**证明：

- 当生成依赖不可用时，链路不会 silent success；
- `/api/agent/stream` 会给出显式终止事件；
- `/api/agent` 聚合接口会给出同一故障语义，而不是伪造结构化成功结果。

本次实际拿到的是：

- **SSE final + `stop_reason=no_model` + `[DONE]`**
- **聚合 API `stop_reason=no_model`**

这属于“显式降级”，但**不是 A02 里 tool-level `dependency_failure` 的机器可读状态**。
