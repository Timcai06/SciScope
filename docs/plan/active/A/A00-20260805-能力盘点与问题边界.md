### 数据依赖链速查（静态路径核对）

- `search_literature`/`summarize_field` → `backend/app/services/retrieval_service.py::search` →
  PostgreSQL FTS（`paper_chunks.search_document`）+ 可选 pgvector 语义臂 + 可选 reranker
- `get_paper`/`compare_papers`/`export_bibliography` → psycopg 直连（`papers`/`paper_authors`/`authors`）
- `recommend_papers` → `backend/app/services/recommend_service.py`（依赖 `paper_embeddings` 表）
- `get_trends` → 直接读 `models/trends/hot_keywords.csv`、`data/analysis/keyword_trends.csv`
- `query_knowledge_graph` → `backend/app/services/graph_service.py`（`output/graphs/*.json` + `coauthor_edges`）
- `verify_claim` → `retrieval_service.search` + `src/models/embeddings.py`（e5）+ `backend/app/services/stance/judge.py`（LLM）+ `stance/store.py::record_stances`（落库）
- `list_disputes` → `backend/app/services/stance/store.py::disputed_claims`（`contradictions` 视图）
- 注册表入口：`backend/app/agent/tools/__init__.py::NATIVE_TOOLS`（11 项；其中 10 项
  `side_effect="read"`，`verify_claim` 为可写 stance 资产的 `side_effect="write"`）→
  `backend/app/agent/tools/base.py::execute_tool`（permit→validate→run→bound）。普通核查默认
  `persist=false`；只有显式 `persist=true` 且 `SCISCOPE_ALLOW_WRITE_TOOLS=1` 才落库。

## 四、结论与下游提示

- A 线六类产品能力中：文献问答/综述/核查/图谱/趋势在当前环境有真实数据路径；**推荐当前阻塞**，
  且检索语义臂覆盖率极低——A01/A02 的产品表述与评测须如实反映这些边界，不得把「词汇检索结果」
  表述为「混合语义检索结果」，不得在 `paper_embeddings` 重建前承诺推荐质量。
- 既有验证等级：离线 `eval_all`（retrieval/trend/recommendation 代理指标）+ 在线 `eval_dialogue`
  （7/7 PASS，2026-07-07）+ `eval_stance`（similarity 控制实验）；尚无论文级答案正确性人工评测
  （A03）与 L3 金标准（E 线）。
- 交接给 A01：意图路由须覆盖「找相关论文 / 总结领域 / 判定 claim 支持/反驳」三类显式意图 +
  未知意图；工具选择可从 SSE 事件（`tool_call`/`tool_result`）看见（`routes_agent.py::/api/agent/stream`）。
- 运行环境固定命令（复现本表）：conda env `ai` + 5433 DSN + `SCISCOPE_EMBEDDER_PATH` 本地路径。
