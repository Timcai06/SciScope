## 一、做了什么

在现有 LangGraph 单循环内加**确定性意图路由层**，不复制第二个 Agent Loop：

1. **新增 `backend/app/agent/intents.py`** —— 确定性意图分类器（无 LLM/网络/随机）：
   - 16 个意图：`skill_*`（4 个技能）、`claim_verification`、`field_review`、
     `trend_analysis`、`paper_compare`、`graph_query`、`paper_recommend`、
     `paper_detail`、`literature_search`、`concept_explanation`、`meta_query`、
     `vague_query`、`unknown`；每类带用户可读 label、首选工具、分类依据 reason。
   - 优先级：技能标记 > claim > 综述 > 趋势 > 对比 > 图谱 > 推荐 > 详情 > **能力说明**
     （提前于宽泛的"文献/论文"检索词，修掉「除了科研文献你还会什么」误判）> 检索 > 概念 > 模糊 > 未知。
2. **`langgraph_runtime.py` 集成**（`_prepare` 节点）：
   - 首个 LLM 调用前分类意图，注入路由引导 system 消息（首选工具 / 澄清约束）；
   - 发射新 **`intent` SSE 事件** `{intent, label, reason}` —— 工具选择可从 SSE 看见，
     只带能力标签与分类依据，**不泄露内部引导提示**；
   - 新增 `_forced_intent_tool_call`：普通（非技能）论断核查问题若模型试图不调工具直接答，
     确定性强制 `verify_claim`（A01：不把论断核查偷换成普通检索）；`_claim_from_question`
     剥离「求证/请问/吗/对不对/这个说法」等壳词提取裸论断。
3. **`events.py`**：`AgentEventType` 增加 `"intent"`；**`routes_agent.py`**：SSE 契约注释同步。
