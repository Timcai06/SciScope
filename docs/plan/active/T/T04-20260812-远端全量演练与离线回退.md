| 次数 | HTTP | 首事件 | 总耗时 | stance | 引用合同 | 引用数 | DONE / error |

| 1 | 200 | 0.004s | 12.259s | supported | ok | 4 | yes / no |

三次均完成，但 verdict 存在 `supported` 与 `partially_supported` 波动。T04 只据此判定运行链、
引用合同和降级纪律可演练，不把它写成 stance 确定性或 L3 质量证明。SSE final meta 没有回传
具体 model 字段，摘要因此保留 `None`，不从 readiness 反推并伪填模型名。

## 4. TUI 在线、重试与离线边界

| 场景 | 结果 | 证据 |
|---|---|---|
| 隔离真实 TUI 首次 `/verify` | 工具与 stance 卡正常；答案合同因关键引用格式不足降级为 `generative_non_evidentiary` | `tui/isolated-*` |
| 同任务有记录重试 | 合同为 `citations ok`，展示 stance、置信度、审计链、边界和谨慎改写 | `tui/retry-*` |
| 固定离线回退 | 不可达后端下 `make tui-demo` 完整播放固定证据流 | `offline/demo-*` |
| 普通 TUI 后端不可达 | 明确 blocked，提示 `make backend`、`/retry`、`/doctor`，不 silent success | `offline/failure-*` |

离线 demo 是确定性 fixture，只能用于断网时说明界面和协议，不能称为实时检索、实时 DeepSeek
或全量数据库结果。首次在线合同失败没有删除，重试成功也不能包装成首次成功。
