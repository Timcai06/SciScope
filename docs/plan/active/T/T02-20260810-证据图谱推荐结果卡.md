## 1. 做了什么

把 TUI 从“只看字符串答案和少量旧卡片”推进到“显式消费 A02/G02/E03 合同并 fail-closed 渲染”：

1. **A02 final contract sidecar**
   - 新增 `answer-contract/v1` 渲染：状态、引文合规、拒答类别、限定条件、来源链、证据句、工具依据。
   - `final` 的 `meta.structured_answer` 现在会在正文答案前显示为独立合同卡。
   - 正文证据遵循显式授权门控：只有 `display_policy.authorized=true` 才显示 `source_field` 与 `evidence_sentence`；缺失或 `false` 一律隐藏，仅保留 `paper_id/title/year/chunk_uid` 审计链。

2. **`verify_claim` 证据卡升级**
   - 读取 stance / 置信度 / `chunk_uid` / `source_field` / `evidence_sentence` / `限定条件`。
   - `证据不足`、`abstained`、`dependency_failure` 不再只剩一句理由，而会保留来源链与拒答边界。
   - 未显式授权的证据正文不会出现在 TUI；若 payload 带 `display_policy.reason`，卡片只显示 `正文隐藏 · <reason>`。

3. **G02 结构化查询卡**
   - `recommend_papers`：显示 `ok/empty/unavailable`、推荐理由、共享关键词、相似度；缺 `paper_embeddings` 时明确 `unavailable`。
   - `query_knowledge_graph`：显示关系类型、邻居、provenance / hash 状态；旧图谱降级会显式写 `degraded_reason`。
   - `get_trends`：显示 `descriptive_only` 边界，不把趋势外推包装成预测。
   - `/trend` 的兜底提示也冻结为“历史趋势 + 描述边界 + 不确定性”，不再生成未来走向式问法。

4. **E03 争议卡**
   - `list_disputes` 现在能显示同一 canonical claim 的 support / contradict / paper_ids。
   - 空争议明确写“空结果不等于不存在科学分歧”。

5. **固定研究线索 SSE fixture**
   - 新增 `reviewGoldenMessages()`，固定包含图谱、推荐、趋势三步，供 T04 演练和测试复用。
