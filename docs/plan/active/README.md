## 协作与状态

- **PASS**：验收证据可复核，才可解锁下游；**REVISE**：有明确可修缺口；
  **BLOCKED**：外部依赖或环境不成立；**PENDING**：尚未开始；**LOCKED**：前置未通过。
- 每次只领取一个原子任务；先记录基线 SHA、预存改动与文件所有权。
- 回报必须给出：任务编号、修改文件职责、验收到测试映射、实际 `rtk` 命令和退出码、
  未运行项、风险/回退，以及 `rtk git diff --check`、`rtk git status --short`。
- 2080 Ti 已完成全量语料导入、chunk/paper embedding、ANN 索引和真实推荐烟测；运行期间采用
  单重计算线、受控线程与资源阈值，未发生 OOM 或阈值越界。Wave 1 技术门禁已关闭；无领域专家时，
  E02 质量门禁仍不能 PASS；讯飞许可或联系人未确认时，E08 保持 `BLOCKED`。
