## 协作与状态

- **PASS**：验收证据可复核，才可解锁下游；**REVISE**：有明确可修缺口；
  **BLOCKED**：外部依赖或环境不成立；**PENDING**：尚未开始；**UNLOCKED**：前置未通过。
- 每次只领取一个原子任务；先记录基线 SHA、预存改动与文件所有权。
- 回报必须给出：任务编号、修改文件职责、验收到测试映射、实际 `rtk` 命令和退出码、
  未运行项、风险/回退，以及 `rtk git diff --check`、`rtk git status --short`。
- 2080 Ti 不可用时，G03 保持 `BLOCKED`；无领域专家时，E01 只能是试运行；无讯飞数据/授权时，
  E08 保持 `BLOCKED`。
