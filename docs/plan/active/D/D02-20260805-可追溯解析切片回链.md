## 目标

把 D01 已准入的记录（`data/admission/staged.jsonl`）变成**可追溯的解析/切片中间层**。
每个 chunk 必须回链：`paper_id`、`source`、`source_file_sha256`、`record_sha256`、
原始文件定位信息、解析器版本、页码或文本范围。

## 每个 chunk 的回链字段

| 字段 | 来源 | 说明 |
|---|---|---|
| `paper_id` / `source` | D01 记录 | 论文级回链 |
| `source_file_sha256` + `source_hash_status` | D01 记录 + 字节核验 | `verified`（字节一致）/ `mismatch` / `unverified`（拿不到字节，**不伪称通过**） |
| `record_sha256` + `record_hash_verified` | D01 记录 + 复核 | 切片时重算 `compute_record_hash` 复核，防中途篡改 |
| `source_file` | `_sciscope_source_path` / `source_file` | 原始文件定位信息 |
| `parser_version` | 常量 `traceable-chunks/v1` | 解析器/切片层版本 |
| `locator` | 切片计算 | 纯文本：`{start_char, end_char, base: normalized_text}`；分页正文：`{page, start_char, end_char, base: normalized_page_text}`；标题+摘要：`{field: title+abstract}` |

## 评审修订（2026-08）

按项目负责人复核反馈修订：

1. **分页正文噪声过滤**（`traceable_chunks.py` pages 分支）：此前 `full_text_pages` 直接切片、
   绕过了噪声防线。修复后：PDF 结构垃圾按整页集合拦截（文档级失败信号）；网页噪声（如
   `Access denied. Enable JavaScript and reload the page.`）按页判定，命中页不切片并写入
   `invalid_full_text_source`（原因含页码），其余正常页照常切片。新增
   `test_paged_web_noise_not_chunked_and_recorded`（评审复现场景）、
   `test_paged_pdf_garbage_not_chunked_and_recorded`、`test_mixed_pages_only_noisy_page_fails`。
2. **回链抽查辅助 `backtrace_chunk`**：按 chunk 的 `locator` 从记录还原原文并验证 span 一致；
   测试覆盖三种 locator 与篡改检测。真实讯飞数据接入后可用于人工抽检，但不作为当前 PASS 门槛。

## 风险 / 回退

- **`source_file_sha256` 核验诚实边界**：无原始字节时记录 `unverified` + 原因（`source_bytes_unavailable` /
  `source_file_not_found`），绝不伪称通过；数据到达后按 `_sciscope_source_path` 提供原始文件即自动核验。
- **PDF 垃圾 / 网页噪声不切片**：复用 `looks_like_pdf_garbage` + 浏览器验证噪声标记；命中即写
  `invalid_full_text_source` 失败状态，不生成 chunk。
- **span 基于规范化文本**：`locator.base` 明确标注 `normalized_text` / `normalized_page_text` / `field_text`，
  避免把规范文本偏移误当原文偏移。
- **回退**：本层独立于既有 `chunks.py` 生产链，出现问题时删除 `src/infra/traceable_chunks.py` 与测试即可，
  不影响 RAG 切片与运行库。
