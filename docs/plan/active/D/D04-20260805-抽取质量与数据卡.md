## 修订记录（2026-08，v2：承接真实盲审）

按复核反馈修订 `extraction_eval` 为 v2（`extraction-eval/v2`）：

1. **record_sha256 唯一匹配**：gold 必须按 `(source, paper_id, record_sha256)` 唯一匹配；
   缺 sha / 版本不匹配 / 同 `(source, paper_id)` 多版本歧义 → **fail-closed** 记入 `unrateable`（原因可查），绝不任选一条；
2. **两阶段人工流程**：阶段 A 盲审填 gold（只读原文，禁止看 D03 输出）；阶段 B 解除盲法后人工裁决
   （`correct`/`incorrect`/`unsure`）——**正确率只来自人工裁决**，程序不再用 `gold_value in actual`
   字符串包含判对错（修复“1”匹配“10”类错误）；无裁决时 `correct=0` + `pending_human_adjudication=True`；
3. **gold_locatable 真正参与**：盲审判定“原文可定位”而 D03 span 无效 → `locatable_mismatch` + 可复查失败例；
4. **模板**：新增 `D04-盲审模板.md`（每列含义、禁止查看 D03 输出的阶段、20 篇分层抽样要求、JSONL 示例）；
5. **硬规则（复核修订，v2.1）**：阶段 A 判定字段本不存在（`gold_present=false`）而系统抽取了 →
   **必为 false positive**，即使阶段 B 误填 `correct` 也不计入正确率（失败例附
   `adjudication_note`：须先回阶段 A 更正 `gold_present` 再重评）——防止“本不应存在的
   抽取”抬高分数；`gold_present=false` 且未抽取 → 裁决 `correct` 正常计入（阴性正确）。
6. **pending 语义（复核修订，v2.2）**：新增 `pending_count`（该字段缺裁决的可评测样本数）；
   **`correctness` 分母改为“已裁决”可评测样本数（n − pending_count）**——pending 样本尚未裁决，
   不当作错误计入，避免未完成裁决拉低正确率；全部 pending 时正确率为 0 且无 CI（无裁决数据）。
7. **未裁决假阳性（复核修订，v2.3）**：`gold_present=false` 且系统已抽取仍必记
   `false_positive`；但若尚无阶段 B 裁决，该样本同时计入 `pending_count`，不得伪装为
   “已裁决错误”进入正确率分母。新增同字段部分裁决回归，锁定每字段分母只计算本字段
   已裁决样本。

## 2. 评测脚本能力（输入 / 输出）

**输入**：
- D03 输出 `structured.jsonl`（`{source, paper_id, schema_version, fields[]}`）；
- gold 标注 `gold.jsonl`：`{source, paper_id, field, gold_present, gold_value?, gold_locatable?}`（**由领域专家/非开发者人工产出，脚本不生成**）。

**输出**（每字段，schema `extraction-eval/v2`）：

| 指标 | 定义 | 分母 |
|---|---|---|
| `n` | 该字段 gold 标注条数 | 分母本身 |
| `extraction_rate` | extracted / n | 字段存在率 |
| `correctness` | correct / (n − pending_count) | 已裁决样本正确率（**不只报抽取成功数**；无已裁决样本显示 0 且 CI 为 null） |
| `locatable_rate` | evidence 完整且 span 有效 / n | 来源可定位率 |
| `rejected_rate` | not_found / n | 拒答率 |
| `blank_rate` | not_found+low_confidence 且无值 / n | 留空率 |
| `ci_low`/`ci_high` | Wilson 95% 置信区间 | 样本数不足时为 null |
| `failures` | 可复查失败例（source/paper_id/field/gold/actual/reason） | — |

失败原因分类：`value_mismatch`（提取但值不符）、`not_extracted:<status>`（该抽未抽/低置信）、`false_positive`（gold 标记不存在却提取）。

## 4. Data Card（数据卡）

> 适用对象：D03 `structured-extraction/v1` 输出的**使用边界**。字段级正确率待 20 篇盲审后回填本卡。

### 4.1 领域偏差
- 抽取为**离线规则**（指示词表中英双语，最小集合），无 LLM；
- 词表覆盖偏重生物医学（patients/mice/cells/患者/小鼠）与机器学习（neural network/transformer/准确率）；
- **材料科学**领域指示词较少 → 预期该领域 `not_found` 率高、`extraction_rate` 低——这是诚实边界，不是缺陷；D04 评测须按领域分组解读。

### 4.2 全文覆盖边界
- D03 只消费 D02 可追溯 chunk：无 `full_text` 的论文只有 `title_abstract` chunk（数值/结果/限制的召回天然受限）；
- 分页正文经 D02 噪声过滤后才可切片；被过滤页不参与抽取；
- 语料本身有 PMC 偏向（D00 盘点），抽取结果同样继承该偏向。

### 4.3 不可用场景
- 无指示词 → `not_found`（拒答），绝不编造；
- 低置信（如结论回退到摘要末句）→ `low_confidence` 且 value 留空、候选句进 `candidates` 待审；
- 来源链断裂（chunk_uid 校验失败）→ chunk 禁止参与抽取，记 `invalid_chunks`；
- 数值规则只收“带单位或含小数”的量与 p 值；孤立整数不算。
