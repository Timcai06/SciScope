> 状态：**模板已就绪；20 篇盲审未完成**（需要 1–2 名不参与 D03 开发的评审者）

## 为什么是两阶段

| 阶段 | 做什么 | 谁能看什么 |
|---|---|---|
| **阶段 A（盲审，先做）** | 只阅读**原论文/可授权片段**，凭自己的判断填写 gold（字段是否存在、原文值、可否定位）。**不得查看 D03 抽取输出**。 | 原文（论文 PDF/可授权片段）、gold 模板 |
| **阶段 B（裁决，后做）** | 解除盲法，对照 D03 输出逐字段裁决：该字段抽取得**正确 / 错误 / 不确定**。 | gold 记录 + D03 输出 + 裁决表 |

程序（`evaluate_extraction`）**不会**用模糊字符串匹配替你判"正确/错误"——正确率只统计你的人工裁决；
未裁决的样本标为 `pending`，不冒充结果。

Wave 0 可先运行 `evaluate_silver_consistency` 检查同批 D02→D03 是否可重现、证据 span 是否可
回链；该结果不是人工审查、不是正确率，不能取代以下两阶段。

## 20 篇抽样要求

- 从**已准入且许可明确**（license 非 unknown）的样本中抽 **20 篇**；
- 分层：覆盖 3 大领域（计算机科学 / 生物医学 / 材料科学）× 至少 2 种语言（中/英）× ≥2 个来源；
- 每篇对 D03 的 6 个字段逐一填写 gold（可能部分字段不存在/不可定位——如实填写即可）；
- 每条 gold 与裁决都带上 `source + paper_id + record_sha256`（**缺 record_sha256 的样本会被程序判为不可评测**）。

## 阶段 A：gold 填写表（每行一条 gold，JSONL 或下表格）

| 列 | 类型 | 含义 | 填法 |
|---|---|---|---|
| `sample_id` | int | 抽样编号 | 1–20 |
| `source` | str | 来源标识 | 从抽样清单复制 |
| `paper_id` | str | 论文稳定 ID | 从抽样清单复制 |
| `record_sha256` | str | 论文版本哈希（64 hex） | 从抽样清单复制，**必填** |
| `field` | str | 六字段之一 | `study_population` / `study_design` / `main_result` / `numeric_findings` / `limitations` / `conclusion` |
| `gold_present` | bool | 原文是否存在该字段信息 | `true` / `false` |
| `gold_value` | str | 原文中的关键表述（简短） | 不存在则留空 |
| `gold_locatable` | bool | 原文中能否定位到该字段 | `true` / `false` / 不确定填 `false` 并在 notes 说明 |
| `notes` | str | 备注（页码/疑问） | 可选 |

JSONL 示例：

```json
{"sample_id": 1, "source": "iflytek", "paper_id": "PX-001", "record_sha256": "3faa…", "field": "main_result", "gold_present": true, "gold_value": "AUC 0.85", "gold_locatable": true, "notes": "摘要第二段"}
```

## 阶段 B：裁决表（每行一条裁决）

| 列 | 类型 | 含义 | 填法 |
|---|---|---|---|
| `sample_id` / `source` / `paper_id` / `record_sha256` / `field` | — | 与阶段 A 同一行对应 | 从阶段 A 复制 |
| `judgment` | str | 人工裁决 | `correct`（抽取正确）/ `incorrect`（错误）/ `unsure`（不确定） |
| `notes` | str | 理由 | 可选（如"把 1 抽成了 10"） |

## 禁止事项

- 阶段 A 期间**不得**打开 `data/admission/structured/` 或任何 D03 输出；
- 不得修改/删除任何一行（新增行请追加并换 `sample_id`）；
- 没有真实许可明确的样本时，**不要临时编造 license**——保持"该样本不可评测"并在记录里注明。

## 交付

- 两个文件：`gold.jsonl`（阶段 A）+ `adjudications.jsonl`（阶段 B）；
- 由评测调用方运行 `run_extraction_eval(...)`，输出 `eval_report.json` 回填 Data Card 字段级正确率。
