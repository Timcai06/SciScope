## 2. 查询解释合同（统一信封）

三类查询统一响应结构：`{status: ok|empty|unavailable, query, data_source,
asset, results, unavailable_reason, note}`。

### 2.1 图谱（kg_asset_v1）
- **读取路径**：`SCISCOPE_KG_ASSET_PATH`（默认 `output/knowledge_graph/graph_asset.json`）；
- **版本校验**：仅接受 `knowledge-graph-asset/v1`；不匹配 → `unavailable`，
  reason=`schema_version_mismatch:got=…,expected=…`；文件缺失 → `kg_asset_file_missing:<path>`；
  JSON 损坏 → `kg_asset_invalid_json`；
- **成功响应**：`asset.{schema_version, module_version, input_fingerprint}` + 关系类型
  （published_in/about/published_in_year）+ 邻居 provenance
  （`paper_id` / `source_id` / `record_sha256` / `corpus_record_sha256` / `record_sha256_status`）；
- **诚实边界**：每个成功/空响应带 note——“关系仅表达论文已有字段（来源/关键词/年份）的
  关系，不构成因果，也不构成对任何科学结论或 stance 的支持”；
- **空查询**（空 value / 无匹配实体）→ `empty`，不抛异常。

### 2.2 推荐
- `paper_embeddings` 不存在（`recommend_service.is_available()==False`）→
  `unavailable`，**reason 固定 `paper_embeddings_unavailable`**（可测试）；
- 有候选 → `ok`（每条含 paper_id/title/year/field/similarity/shared_keywords/factors）；
  无候选 → `empty`；**无任何 fallback 成“语义推荐成功”**。

### 2.3 趋势
- 成功响应带 `asset.data_version`（文件 mtime+size = 分析产物构建时间戳）与
  `asset.time_range`（从 CSV 表头 `normalized_df_<year>` 推导；`ytd_<max>_normalized_df`
  列存在则标注 YTD，纯内容驱动、确定）；
- **预测诚实标注**：note 固定声明“forecast 为基于历史年份列的外推估计，
  **未经历史回测验证，不得作为预测结论**”；item 字段改名“预测目标年份(未验证外推)”；
- 文件全缺 → `unavailable`（reason=`trend_data_unavailable`）；无匹配 → `empty`（含 suggestions）。

### 2.4 旧路径兼容（不静默换源）
- `community` / `author`：资产无等价能力 → 旧 `graph_service`，`data_source="legacy_graph_export"`；
- `keyword`/`topic`：资产可用 → `kg_asset_v1`；不可用 → 降级旧 keyword 图，响应带
  `degraded_reason="kg_asset_unavailable:…"`；
- `paper`/`source`/`year`：资产不可用 → 结构化 `unavailable`（旧路径无等价查询，
  宁可不可用也不换源伪装）。
