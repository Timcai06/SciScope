## 2. 图谱 schema、节点边定义与 provenance 设计

**输出顶层契约（G02 直接消费）**：`schema_version`（`knowledge-graph-asset/v1`）+
`module_version` + `build.{input_records, input_fingerprint, record_hash_scheme, node_id_scheme}`
+ `schema` + `nodes` + `edges` + `stats` + `warnings`。

**节点（4 类，可读/稳定 id）**：

| 类型 | id 配方 | 属性 |
|---|---|---|
| `paper` | `chunks.paper_uid(record)`（直接复用现有链函数） | `paper_id, source, source_id, title, year(int|None), field, record_sha256(null|D01), corpus_record_sha256, record_sha256_status` |
| `source` | `source:<source>` | `name` |
| `topic` | `topic:<keyword>`（关键词原文去重，不做词形归一，保留消歧括号） | `keyword` |
| `year` | `year:<yyyy>`（仅合法整型年份 `1000..2100`） | `year` |

**边（3 类，均携带 provenance）**：

| 关系 | 语义 | provenance |
|---|---|---|
| `paper → source`（`published_in`） | 论文发布/收录于该来源 | `{paper_id, source_id, record_sha256, corpus_record_sha256, record_sha256_status}` |
| `paper → topic`（`about`） | 论文标注了该关键词（数据已有字段，非抽取结论） | 同上 |
| `paper → year`（`published_in_year`） | 论文发表于该年份 | 同上 |

**provenance 设计**：每条边固定 `{paper_id, source_id, record_sha256, corpus_record_sha256, record_sha256_status}`。

**哈希诚实语义（复核意见 HIGH 修复）**——两个字段严格区分，不可混用：
- `record_sha256`：**真实 D01 合同哈希**，仅当输入记录自带该字段时保留（`verified`）；
  输入有但内容不匹配 → `mismatch`；`papers_corpus.json` 为处理后投影，不含 D01 的
  license/usage_rights/原始文件哈希等合同字段 → **`null` + `d01_unavailable`**，不用于跨阶段回链；
- `corpus_record_sha256`：对当前 processed corpus 投影现场计算（`compute_record_hash`，
  D01 哈希算法），仅供本资产内审计，**不等于 D01 哈希**。

**去重/空值/非法策略（写入 `schema.policy`，均有测试）**：
- 重复论文：同一 paper_uid 只保留首条，后续跳过 + `duplicate_paper` warning；
- 缺关键词（keywords 空/缺省）：建 Paper 节点、不建 `about` 边，计入 `skipped.topic_edges`；
- 非法年份（非 int 或越界）：建 Paper 节点、不建 `published_in_year` 边，计入 `skipped.year_edges`；
- 未知来源（source 空）：不建 Source 节点与 `published_in` 边，计入 `skipped.source_edges`；
- 关键词列表内空项：过滤 + `empty_keyword_item` warning。

**可重复性**：输出不含时间戳/随机量，相同输入 → 字节级相同文件（测试断言）；
`build.input_fingerprint` 为输入规范化 sha256，供审计输入版本。

**诚实边界**：schema 中每条边的 `meaning` 只表述"数据已有字段的关系"；不输出任何
"支持某科学结论"断言（该能力仅归 E 线 L3）。
