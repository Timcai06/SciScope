## 2. 指标定义、切分规则与数据边界

**数据**：`data/analysis/keyword_trends.csv` 的 `normalized_df_<year>`（2022–2026）；
仅保留 `doc_count >= 30` 且非噪声关键词（`is_noise_keyword`），与既有 `eval_trends.py` 同口径。

**固定滚动切分**（只使用截至目标年前一年的数据，无未来泄漏）：
- 切分 1：train `2022-2023` → 目标 `2024`；
- 切分 2：train `2022-2024` → 目标 `2025`；
- **2026 为 YTD，不作为回测目标**（诚实边界：不拿不完整年份当真实值）。

**模型**：
- `trend_model`：现有趋势逻辑（`src.models.trends._fit_forecast` 的 damped Sen's-slope
  外推，`forecast = last + 0.5*sen_slope`——与线上 `get_trends`/`hot_keywords.csv` 同一函数）；
- `last_value`：持平基线 `pred = 最后观测值`；
- `moving_average`：`pred = 最近 2 年均值`。

**指标**（每个切分 + 汇总，均带分母 n 与时间窗口）：
- `MAE`；`sMAPE`（分母为 0 的样本按 0 贡献，不除零）；
- `Spearman rho/p`（pred↔actual 横截面秩相关；p 用 Fisher z 变换 + 正态近似，纯标准库）；
- 方向 `balanced accuracy`（up/down 两类 recall 均值；flat 计入整体一致率但不进 recall 分母）。

**边界判定**（写入结果 `decision`）：
`descriptive_only = True` 当且仅当 trend 未能在**严格多数切分点**（> 半数）的 MAE 与 sMAPE
上都严格优于最佳 naive，**或** Spearman 不显著（任一切分 p ≥ 0.05）。

## 3. 关键结果（真实数据，min_doc_count=30）

| 切分 | n | trend MAE/sMAPE | last MAE/sMAPE | ma MAE/sMAPE | 最优模型 |
|---|---|---|---|---|---|
| 2022-23→2024 | 1998 | 0.000524 / 0.598 | **0.000509** / **0.503** | 0.000549 / 0.504 | last（MAE 与 sMAPE） |
| 2022-24→2025 | 1998 | 0.000385 / 0.561 | **0.000349** / 0.421 | 0.000385 / **0.408** | last(MAE) / ma(sMAPE) |

- Spearman 显著（rho≈0.69–0.74，p≈0）——**排名方向有信号**；
- 但绝对误差（MAE/sMAPE）两个切分 trend 均未超过最佳 naive：`mae_wins=0/2, smape_wins=0/2,
  required_majority=2`；
- **判定：`descriptive_only=True`**——现有趋势逻辑只能称"描述性趋势"（统计描述历史
  方向/波动），**不得称预测能力、不得给出研究方向预测结论**；
- 失败案例（trend 绝对误差 Top5，含真实数值）已写入结果表：热点波动关键词
  `cond mat mtrl sci`、`cancer`、`retrieval augmented generation`、`large language model` 等
  误差最大——方向外推对高波动热词最不可靠，是主要适用边界。

## 8. 边界结论（供下游与文档使用）

现有趋势逻辑（`_fit_forecast` 外推）在本数据集上的**绝对误差预测能力未超过持平/移动平均
基线**（0/2 切分点胜出），仅排名方向（Spearman）显著。因此：
- 趋势输出与文档**只可称"描述性趋势"**（描述历史方向/统计显著性/波动），
  **不得写成预测能力或研究方向预测结论**（与 G02 的"预测未验证外推"标注一致并给出回测证据）；
- 高波动热点关键词（cancer、LLM、RAG 等）是趋势外推的主要失败区，方向辅助须避免对它们下断言。
