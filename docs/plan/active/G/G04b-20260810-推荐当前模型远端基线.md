## 3. 为什么仍不能整体 PASS

本轮只完成“当前推荐实现”的真实运行基线，还没有完成计划要求的 popularity、TF-IDF/keyword、
纯 dense 与当前融合模型的统一对照，也没有可审计的 diversity、novelty、延迟分布和失败案例主表。
因此不能声称当前模型优于强基线。

更重要的是，same-field、shared-keyword 和 embedding similarity 都是自动代理指标，不是研究者满意度、
新颖发现或科研效率提升的证据。真实用户/领域专家盲评继续 `BLOCKED`。
