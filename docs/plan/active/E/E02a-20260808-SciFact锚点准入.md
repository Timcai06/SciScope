## 5. 样本与标签统计（dry-run 实测）

| split | claims | with_evidence | 缺失率 | label 分布 | doc 引用可解析率 | sentence 引用有效率 | corpus |
|---|---|---|---|---|---|---|---|
| train | 809 | 505 | 0.3758 | SUPPORT 533 / CONTRADICT 424 / NEUTRAL 304 | 1.0 | 1.0 | 5183 |
| dev | 300 | 188 | 0.3733 | SUPPORT 216 / CONTRADICT 122 / NEUTRAL 112 | 1.0 | 1.0 | 5183 |
| test | 300 | 0 | 1.0 | NEUTRAL 300（官方无标注，仅盲评） | — | — | 5183 |

注：NEUTRAL 为官方无证据 claim 的隐式类别（官方 rationale 标签仅 SUPPORT/CONTRADICT）。
关键校验：**evidence doc key 是 str、corpus doc_id 是 int，validator 做 int 归一后再查引用，
否则会误报 188/300 缺失**——这是数据本身的类型不匹配坑，已处理。

## 8. 风险与回退

- **风险 1（浮动标签）**：S3 `release/latest` 无固定 commit。缓解：已记录下载日期 + 上游
  tree SHA + 逐文件哈希；若上游更新导致哈希变化，validator 会 fail-closed 并提示更新 manifest。
- **风险 2（许可）**：corpus 摘要 ODC-By 1.0 允许再分发但需署名；提交包若含 corpus 须附
  许可与来源（`scifact_anchor.json` 已记录）。claims 为 CC BY 4.0。
- **风险 3（类型坑）**：evidence doc key 为 str、corpus doc_id 为 int，引用校验必须 int 归一
  （已实现并有测试 `test_dry_run_stats_ok` 覆盖 1.0 可解析率）。
- **回退**：若上游不可达，使用已下载的 `data/scifact/raw/` 与固化哈希离线校验；若哈希与
  官方不符，fail-closed 阻止进入任何评测流程。
