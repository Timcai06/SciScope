## 1. 交付物与封装事实

- 外层：`environment.tar.gz`，实际是 gzip，原始文件名记录为 `environment.zip`；大小
  `15,419,870,954` bytes；接收侧 SHA-256：
  `b59220e9c5986670403b6d24181de2b6cc719e110a1ceaf8e630c427cc21e47d`。

  5,568 个文件的压缩数据无 CRC 错误。
- 审计只读取 ZIP 中央目录和压缩内容进行 CRC；没有将 PDF 解压到工作语料目录。

## 3. 准入阻塞

包内没有 README、license、manifest、metadata、schema、usage-rights、字段映射或授权说明。
因此 D01 要求的 `license/usage_scope`、`usage_rights`、语言、年份、版本/更正状态均不能从交付包
直接证明。机器可验证的阻塞项为：

1. `metadata_files_missing`；
2. `license_unverified`；
3. `usage_rights_unverified`；
4. `field_mapping_unverified`；
5. `zero_byte_files`。

在出题方补充书面使用范围前，该批数据只能留在受控 incoming 区；禁止进入 canonical、PostgreSQL、
embedding 和公开导出。即使文件名指向公开预印本，也不能用来源常识替代本批交付授权。
