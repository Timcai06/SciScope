# E03｜同一 canonical claim 的争议三读工程集成

- 状态：`工程 live PASS / 质量 REVISE`
- 日期：2026-08-10
- 边界：只验证一次受控写入与三条读取路径的一致性；不衡量 stance judge 的科学质量，也不是正式 L3 金标准。

## 已实现的契约

一次 `verify_claim({claim, persist: true})` 仅在同一 canonical claim 下同时得到已采信的
`SUPPORT` 和 `CONTRADICT` 证据时，才会将两条记录写入 stance 资产。`contradictions` 视图现在
同时返回聚合 `paper_ids`；API `/api/disputes`、Agent `list_disputes` 和 MCP resource
`sciscope://disputes/recent` 都读取同一个 row 形状，因此可对账 claim 和来源 paper IDs。

写入返回数与应写入数不一致时，`verify_claim` 返回 `资产写入.状态=未写入`，不会把未确认的
派生资产报告为可读取争议。

## 可复现 fixture 证据

专项测试 `backend/tests/test_e03_dispute_three_reads.py` 使用单一受控 claim
`咖啡能降低心脏病风险`，一次 `persist=true` 核查产生：

| 层 | 断言 |
|---|---|
| 写入/数据库形状 | 同一 `claim_norm` 下 `E03-SUPPORT` 为 `SUPPORT`、`E03-CONTRADICT` 为 `CONTRADICT` |
| API | 同一 claim 与 `paper_ids=[E03-SUPPORT, E03-CONTRADICT]` |
| Agent tool | 同一 claim 与同一 paper IDs |
| MCP resource | 同一 claim 与同一 paper IDs |

运行（项目测试环境）：`rtk make test-backend`；专项与相关回归会覆盖
`test_e03_dispute_three_reads.py`、`test_disputes.py`、`test_mcp_server.py`、`test_stance_store.py` 和
`test_verify_claim_stance.py`。

这不是“分别核查相反句子”的伪争议：fixture 的正反证据在**一次**相同 claim 的 judge result 中返回。

## live PostgreSQL 证据与质量边界

本机原 `sciscope-db` 已停止，且宿主 `5433` 当前由另一项目测试库占用。为避免误连或中断其他项目，
复用停止状态的 `sciscope_pgdata` 数据卷，在隔离端口 `55433` 启动临时验证容器。只读对账为
`papers=159,164`，确认是 SciScope 数据库后应用当前 `stance.sql`。

新增可选 live gate `test_e03_live_postgres_three_reads`：只有显式设置 `SCISCOPE_E03_LIVE_DSN` 才运行；
它对同一 claim 执行一次真实 `verify_claim(persist=true)`，随后从 PostgreSQL view、HTTP API、Agent tool
和 MCP resource 对账 claim、正反计数与 paper IDs，最后在 `finally` 中按 `claim_norm` 精确删除测试行。

实际命令：

```text
rtk test env SCISCOPE_E03_LIVE_DSN=postgresql://tim@127.0.0.1:55433/sciscope \
  /opt/homebrew/Caskroom/miniconda/base/envs/ai/bin/python -m pytest \
  backend/tests/test_e03_dispute_three_reads.py -q
```

结果：`3 passed`；清理后测试 claim 行数为 `0`。首次在已有视图上应用 schema 时还发现
`paper_ids` 插入旧列中间会导致 PostgreSQL 拒绝 `CREATE OR REPLACE VIEW`；现已把新列追加到视图末尾，
保持旧列顺序，重新迁移成功。服务查询使用显式列名，返回契约不变。

该 live gate 的 judge 与检索候选是确定性 fixture，只隔离验证真实持久化和三读协议；它不是自然语料上的
stance 质量或应用成效证明。正式双语 Gold、专家裁决和真实科学争议案例仍为 `REVISE`。
