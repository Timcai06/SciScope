\subsection{架构决策记录}

\begin{plainbox}
\begin{itemize}
  \item \textbf{PostgreSQL/pgvector 是正式服务层}（修订旧稿"轻量底座"决定）; 16 万论文/36 万+ 片段/768 维向量。
  \item \textbf{共享数据契约}: \texttt{src/data\_contracts/}（由 data\_pipeline 迁入）, backend 与 src.harvest 共用一套 Paper 口径。
  \item \textbf{证据层独立成包}: \texttt{backend/app/services/stance/}（store.py 已迁入, L3 后续扩展）。
  \item \textbf{DeepSeek 是正式生成后端}; 本地 LLM 可选下载, 用 Mock 兜底。
  \item \textbf{协议即正门}: API / SSE / MCP tools + resources; Go TUI 只是消费者之一。
  \item \textbf{双报告共享口径}: 原始/分析/处理/运行库四层数字分开, 诚实边界共用。
\end{itemize}
\end{plainbox}

\subsection{完成标准}

\begin{designbox}{完成定义}
当且仅当: 本机全量库可一键重建并演示; verify\_claim 对正反论断给出可解释的不同判定,
低置信如实拒答, LLM 不可用时不输出"强支持"; 争议地图通过 API/Agent/MCP 三条路径可读;
OpenCode 作为外部 agent 真实调用过一次并留下产物; 两份报告以要素服务化口径一致收束——
SciScope 才算站上国赛主线。Infra 的完成标准是让这些能力更稳定、更可复现,
而不是替代它们。
\end{designbox}
